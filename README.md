# DataMetrics TV Carousel

Fullscreen looping carousel for the SAX DataMetrics technology story — built for office TV display.

**Live:** https://caylinbatt.github.io/datametrics-tv-carousel/

Source content: [consulting.saxadvisorygroup.com/technology](https://consulting.saxadvisorygroup.com/technology)

## Controls
- **F** — fullscreen
- **Space** — pause / resume
- **← →** — previous / next
- Auto-advances every 9s (close slide 12s)

## Local
Open `index.html` in Chrome, or:

```bash
npx serve .
```
